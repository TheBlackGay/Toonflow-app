# 生产链路 P2 生产闭环

更新时间：2026-10-12

## 闭环规则

生产面板的最终导出现在只接受当前生产清单中的完整视频集合，并按镜头 `order` 排序。服务端会重新读取生产清单，校验每个镜头都有视频 `outputPath`，再比对客户端提交的片段列表；缺镜头、媒体类型不符、顺序不符都会返回 `409`。

前端在所有镜头生成视频前禁用“开始导出”，并显示未就绪原因。生成完成后，任务同步将输出路径回写镜头，导出任务完成后再将 `exportedPath` 写回生产清单。

```text
脚本导入 -> 镜头清单 -> 批量生成 -> 任务同步 -> 视频输出齐全 -> 按序导出 -> exportedPath
```
