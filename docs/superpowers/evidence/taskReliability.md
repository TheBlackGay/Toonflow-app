# 生产链路 P3 任务可靠性

更新时间：2026-10-12

媒体任务记录新增以下可恢复信息：

- `attempt`：每次真正进入运行态时递增，重试不会丢失历史次数。
- `startedAt` / `finishedAt`：标记本次执行边界，便于定位卡住或中断任务。
- `errorCode`：稳定区分 `CANCELLED`、`SERVICE_RESTARTED`、`FFMPEG_REQUIRED` 和普通生成失败。
- 任务文件读取和写入继续使用工作区锁与原子写入；重启恢复会把遗留的排队/运行任务标为可重试失败。
- 任务、生产清单和导出任务写入在遇到同进程 `EBUSY` 时短暂等待后重试，批量创建任务不会因前一个任务的状态落盘而失败。

生产面板现在对排队中和运行中的镜头提供取消入口，对失败和取消的镜头保留重试入口。取消不会伪造成功结果，任务状态和生产清单仍通过同步接口更新。

验证：Server/Provider TypeScript、Web Vue 类型检查和 `git diff --check` 通过；真实 HTTP 已验证批量任务、`FFMPEG_REQUIRED`、状态同步、成功生成、运行中取消、取消后立即重试和重启恢复。取消与重试之间增加了执行实例校验，旧执行器不能覆盖新 attempt 的状态。
