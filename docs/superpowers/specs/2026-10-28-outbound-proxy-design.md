# 全局服务端出站代理设计

## 目标

在设置页面提供全局服务端出站代理配置，支持用户部署局域网代理网关。代理仅影响 Toonflow 服务端发起的外部 HTTP(S) 请求，不影响浏览器到 Toonflow 自身 API 的连接。

## 方案

服务端在应用初始化时读取 `settings.network.outboundProxy`，通过统一包装 `globalThis.fetch` 使用 Bun 原生 `RequestInit.proxy`。包装器保存当前代理地址，设置保存成功后即时更新运行时配置，因此无需重启服务。所有直接使用全局 `fetch` 的服务端模块和通过 provider 注入的 `tool.fetch` 自动共享该配置。

代理地址允许 `http:`、`https:`、`socks5:`、`socks5h:`，支持用户名和密码；不得包含路径、查询参数或片段。空字符串表示关闭代理。代理请求失败直接向上抛出，不自动绕过代理。

## 设置界面

设置侧栏新增“网络代理”页面。页面包含代理地址输入框和说明，输入示例为 `socks5://127.0.0.1:1080`；留空关闭代理。沿用现有设置 store 的深度监听和保存队列。

## 服务端改动

新增网络代理运行时模块，负责地址解析、校验、当前配置保存和 fetch 包装。`createApp` 在动态加载路由、初始化 provider 前应用当前设置；设置保存路由在持久化成功后更新运行时配置。保存接口为 `network.outboundProxy` 增加 Zod 字段校验。

## 错误处理与验证

无效代理地址在设置保存时返回参数错误。网络连接失败保持底层错误语义。执行服务端 `bun run typecheck` 和构建；路由文件未新增时不运行路由生成。禁止新增测试文件。
